# Day 3 - Student Grade Calculator

## Project Description

A JavaScript project that calculates a student's total score, average, percentage, grade, and performance remark.

This project is an upgrade from Day 2 by adding decision-making using conditional statements.

## What I Learned

- JavaScript conditional statements
- `if` statements
- `else if` statements
- `else` statements
- Comparison operators
- Using conditions to make decisions
- Updating webpage content using JavaScript

## Features

- Calculates total score from five subjects
- Calculates average score
- Calculates percentage
- Assigns grades based on average score
- Displays performance remarks

## Technologies Used

- HTML
- CSS
- JavaScript

## Grade System

| Average Score | Grade |
|---------------|-------|
| 90 - 100 | A |
| 80 - 89 | B |
| 70 - 79 | C |
| 60 - 69 | D |
| Below 60 | F |
