# Day 4 - ATM Menu System

## Project Overview

This project demonstrates how to use JavaScript `switch` statements to build a simple ATM menu. Based on the selected option, the program displays the corresponding banking service.

## What I Learned

- The `switch` statement
- `case`
- `break`
- `default`
- When to use `switch` instead of `if...else`
- Displaying dynamic content in the browser using JavaScript

## Technologies Used

- HTML
- CSS
- JavaScript

## How It Works

The user selects an ATM option by changing the value of the `option` variable. The program uses a `switch` statement to determine which banking service to display.

### ATM Options

- 1 - Check Balance
- 2 - Withdraw Money
- 3 - Deposit Money
- 4 - Transfer Money
- 5 - Change PIN
- 6 - Exit
