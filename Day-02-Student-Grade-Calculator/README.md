# Day 2 - Student Grade Calculator

## 📖 Overview

This project is part of my **30 Days of JavaScript Bootcamp**.

The Student Grade Calculator takes the scores of five subjects, calculates the total score, average score, and percentage, then displays the results dynamically on a webpage using JavaScript.

## 🎯 Learning Objectives

In this project, I practiced:

- Declaring variables with `let`
- Using arithmetic operators (`+`, `/`, `*`)
- Working with template literals
- Performing calculations in JavaScript
- Displaying dynamic content using `innerHTML`

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

## ✨ Features

- Displays the student's name
- Displays scores for five subjects
- Calculates the total score
- Calculates the average score
- Calculates the percentage
- Shows all results in the browser

## 📂 Files

- `index.html`
- `style.css` *(or `grade.css` if that's what you used)*
- `script.js`


## 💡 What I Learned

This project helped me understand how to use variables, arithmetic operators, template literals, and JavaScript to perform calculations and display information dynamically on a webpage.
