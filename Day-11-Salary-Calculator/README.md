# 💼 Day 11 - Salary Calculator

## 📖 Project Overview

This project demonstrates how to use JavaScript functions with parameters and return values to calculate an employee's salary. The salary is calculated in one function and displayed in another, showing how functions can work together while keeping responsibilities separate.

## ✨ Features

- Displays employee information
- Calculates salary based on hours worked and hourly rate
- Uses function parameters
- Uses the `return` keyword
- Separates calculation logic from display logic
- Dynamically updates the webpage using JavaScript

## 🧠 What I Learned

- Creating reusable functions
- Passing data using parameters
- Returning values with `return`
- Calling one function from another
- Storing returned values in variables
- Using `innerHTML` to display results
