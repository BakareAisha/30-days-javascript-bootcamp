# ⏳ Day 8 - Countdown Timer

## 📖 Project Overview

This project demonstrates how to use a `while` loop to create a countdown timer from 10 to 1. After the countdown finishes, a "Time's Up!" message is displayed.

## ✨ Features

- Counts down from 10 to 1
- Displays numbers dynamically
- Shows a completion message
- Styled with CSS

## 🧠 What I Learned

- How `while` loops work
- The importance of updating loop variables
- How to avoid infinite loops
- Building HTML dynamically

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
