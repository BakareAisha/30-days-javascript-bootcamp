# Day 6 - Number Counter

## Project Overview

This project uses a `for` loop to display numbers from 1 to 10 in the browser dynamically.

## What I Learned

- How `for` loops work
- How to use `i` as a loop counter
- How to build HTML using template literals
- Why `+=` is used to append content
- Why `innerHTML` should be updated after the loop
